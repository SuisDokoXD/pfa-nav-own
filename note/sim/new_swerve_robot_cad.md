# 新舵轮实车 CAD 转仿真网格：现状与阻塞点

数据源：`D:\code\src\sight\model\`（SolidWorks 2025 导出）

| 文件 | 大小 | 读入结果 |
|---|---|---|
| `轮组总装.STEP` | 22 MB | 70 个实体零件，AP214，零件名完整 |
| `升降云台发射机构.STEP` | 149 MB | 127 个实体零件 |
| `新舵轮.STEP` | 287 MB | 732 个叶子零件（含子装配展开） |

格式确认：`FILE_SCHEMA = AUTOMOTIVE_DESIGN`（AP214），`PRODUCT` 50 条 + `NEXT_ASSEMBLY_USAGE_OCCURRENCE` 72 条，
中文名以 `\X2\...\X0\` 转义保存，读入后为原始中文名（`XROLL116包胶轮`、`自制交滚上盖`…）。
坐标：SolidWorks 是 Y 向上，转 Gazebo 用 `(x, y, z) -> (x, -z, y)`。

## 实测数字（STEP 内部坐标，mm）

- 轮胎 `XROLL116包胶轮`：直径 **116.0**、宽 **30.1**，即半径 **58.0**（PCA 定轴，包围盒因转向角被撑成 119×126×95，不能直接用）
- 4 个 `轮组总装` 实例的包胶轮轮心，构成 **233.7 × 233.7** 的方阵；四个轮子 X/Z 各差 7.5 mm，说明模块带约 2° 转向角
- 轮心高度（Y）= **-12.1** → 地面在 Y = **-70.1**
- `新舵底板` 300 × 300 × 4

与现有仿真的差距（`rm25_example_robot.def.xmacro`、`chassis_wheel.def.xmacro`）：

| 项 | 现仿真 | 新底盘实测 |
|---|---|---|
| 轴距 | 0.414 m | 0.2337 m |
| 轮距 | 0.388 m | 0.2337 m |
| 轮半径 | 0.0758 m | 0.0580 m |
| 轮宽 | 0.0452 m | 0.0301 m |
| wheel joint z（=底盘 link 离地） | 0.076 m | 应为 0.058 m |

结论：**只换网格不够**。半径差 17.8 mm，直接替换会让四个轮子悬空/陷地，
必须同时把 `chassis_height`（0.076 → 0.058）、轮子 joint 的 x/y、碰撞圆柱半径、`inertia_cylinder` 一起改。

## 阻塞点：整车与云台两份 STEP 的零件没有装配到位

按 `XCAFDoc_ShapeTool` 展开装配树后，逐零件包围盒显示：

- `新舵轮.STEP`：4 个 `轮组总装`（各 72 件）与 4 块 `装甲板整体` 位置自洽；
  但 `升降云台发射机构` 那 231 个零件散布在约 2 m 范围内，`26 主控模块`、`灯条模块 LI01`、
  `RFID 垫板` 等顶层零件距轮心 0.5～1.1 m；另含 `地面`、`小装甲限定面`、`云台干涉范围`、
  `轮组范围`、`轮组干涉范围2` 这类辅助/包络体（已按名字排除）。
- `升降云台发射机构.STEP` 单独读入：bbox = **1941 × 2072 × 2042 mm**，零件互不共位。
- `轮组总装.STEP` 里 `包胶轮` 与 `自制交滚上/下盖` 也不同轴（合并包围盒 x 方向拉到 -177 mm），
  轮胎本身是干净的单体，其余零件浮动。

也就是说这三份 SLDASM 在导出时处于「零件未完全定位」状态，不能按名字分组成 link 网格。

## 需要机械那边做的（二选一）

1. 在 SolidWorks 里打开每个装配体，看特征树里有没有「(-) 未定位」的零件，
   全部配合/固定后 `Ctrl+B` 重建，再另存 STEP；或
2. 分模块各导一个 STEP：底盘总装、云台 yaw、云台 pitch（含发射机构）、单个轮组。

导出后自检：用记事本搜 `PRODUCT(`，应看到几十上百条零件名；只有一两条说明存成了零件。

## 工具

`tools/sim/cad_to_robot_mesh.py`：STEP → 按 link 分组 → 定向/转米 → STL + JSON 报告。

```bash
# 列出装配体里所有零件（名字/尺寸/体积/所属子装配）
python3 tools/sim/cad_to_robot_mesh.py --step 轮组总装.STEP --list

# 轮胎网格：以轮胎本体定坐标，轮心到原点、轮轴摆到 Y
python3 tools/sim/cad_to_robot_mesh.py --step 轮组总装.STEP \
    --out rm25_wheel.stl --frame wheel \
    --include 包胶轮 --anchor 包胶轮 --deflection 0.1 \
    --report rm25_wheel.json
```

产物示例：`rm25_wheel.stl`，半径 58.0 mm、宽 30.1 mm、4696 面、0.22 MB，
包围盒 x/z ∈ [-0.058, 0.058]、y ∈ [-0.016, 0.014]（已转米，轮心在原点）。

依赖：`pip install cadquery-ocp numpy`（本机 7.8.1.1 可用）。
